DataLund Resource Load

See who is busy when. People (or teams) on tasks over a clear timeline.

AppSource Help page. Pair with DataLund Gantt for the plan — this visual answers who is loaded. For questions, use Support.

Features

  • One row per person or team
  • Assignment bars with optional progress fill
  • Overlaps stack in swimlanes inside the resource row
  • Load badge shows peak concurrent assignments in the visible window
  • Density presets (Compact / Comfortable / Large / Custom) — Format → General
  • Optional time window from today (3 / 6 / 9 / 12 months) — Format → General
  • Cross-filter, tooltips, today line, and weekend shading
  • No network calls — runs in the Power BI sandbox

Fields

  • Resource, Task, and Start Date (required)
  • End Date and/or Duration
  • Optional: Progress, Group, Tooltips

How load is shown

Overlapping assignments on the same person stack in small vertical lanes. A numeric badge on the label shows the maximum concurrent count in the visible time window.
